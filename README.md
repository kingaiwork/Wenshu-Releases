# 文枢 WENSHU

**文件，只在你自己的地方办公。**

文枢是一款免费、开源的办公套件：不用注册账号，没有官方云，文档只存在你自己绑定的存储里。文字、表格、演示、PDF 四个入口装在一个应用里，Windows 和 macOS 都能装。

## 打开 Office 文件，改完存回去

docx、xlsx、pptx 都由文枢自研的通道打开和保存，同事发来的文件不用先转格式。自研通道拿不下的复杂文档，还有兼容模式兜底：调用本机装着的 LibreOffice 打开、先看全、能转 PDF，不硬撑着编辑到走样。态度就一条：能编辑的编辑，只能看的先看全，不让你的内容在转换里悄悄丢东西。

**Writer 文字**——写文档的地方。段落、标题、列表、表格、图片、脚注批注这些日常件都在，往返保存不丢内容。界面上方单独留了「公文」入口，党政机关公文的套版和 28 条规则体检都在里面。

![Writer 文字：打开一份 docx 接着改](docs/screenshots/02-writer.png)
*Writer 文字：打开一份 docx 接着改；公文套版和体检在上方「公文」入口里。*

**Calc 表格**——公式在本地算。大文件走流式读取加延迟计算，十万行量级的表也开得动（开发期实测口径，见详细介绍）。透视表能原样带回，Excel 里打开仍是活的。

![Calc 表格：给已有的 xlsx 改公式、填数据](docs/screenshots/03-calc.png)
*Calc 表格：给已有的 xlsx 改公式、填数据，存回去还是 xlsx。*

## 文件在你手里，不在别人服务器上

文枢没有自己的服务器。我们说的「数据不出你的设备」，意思是：文件默认只保存在你绑定的文件夹或网盘里，我们没有服务器，也看不到你的任何文档。

想跨设备，就在设置里绑一个你自己的存储：本地的另一个文件夹、系统云盘同步文件夹，或者 WebDAV——坚果云、Nextcloud、群晖都行。绑谁、用谁，我们不经手。本地文件永远是真源，绑定的存储只是镜像。

两台设备同时改了同一份文档，同步时不会互相覆盖：系统留一份冲突副本，两份都在，你回头在设置里选留哪版，落败的那版进版本历史。每次保存还会往你绑定的存储里记一版历史，每份文件留最近 30 版，改坏了能往回翻。

怕文件放在网盘上不踏实，可以开客户端加密：口令在你手里，内容加密之后再写出去，文件名保持原样。口令丢了，文件就解不开了，没有后门，这一点先讲清楚。

**Impress 演示（实验版）**——能打开、编辑、保存 pptx；表格、图表、动画这些元素在文件里原样保留，只是编辑器里暂不显示。丑话说在前面：编辑模式打开外部 pptx 目前还不稳定，重要稿子请先用「兼容查看」看版式。这一块还在打磨，所以这次没放演示界面的截图。

## PDF 零碎活，不用再开网页工具

看 PDF 加上一组小工具：合并、拆分、提取和删除页面、旋转、文字和图片水印、页码、页眉页脚、转图片，还有给 PDF 设密码的 AES-256 加密（桌面版）。全部在本机处理，文件不出电脑，结果另存新文件、永不覆盖原件。平时最烦的那种「把三个 PDF 合成一个再发出去」，拖进工具箱点合并，完事。

## 已知限制（0.1.0）

逐条点名，免得你踩坑之后才发现：

- **Impress 演示是实验版**：编辑模式打开外部 pptx 目前不稳定，可能出现白屏；表格、图表、动画在编辑器里不显示（文件里保留，存回去还在）。
- **.docx 的文本框**打开后会变成普通段落：文字一字不少，框的位置和环绕样式保不住。**公式**会变成纯文字，根号、分式这类结构保不住，需要公式的文档请回 Word 处理。
- **.xlsx 里的图表**进不了编辑器，打开后保存会把图表存丢；带图表的工作簿请先用兼容模式看，不要在文枢里保存。条件格式、数据验证、边框、行高列宽在打开保存后也会丢——数字和公式本身不受影响。
- **PDF 合并**后，原文件各自的书签（大纲）保不住；**压缩**只做结构层面的整理，图多的文件压小不了多少，界面上会写明实际变化。
- **WebDAV 同步**已在本地测试服务上全链验过，坚果云、Nextcloud、群晖三家真实服务还没逐家实测。绑正式文档之前，先拿几个不重要的文件试一轮同步。
- **客户端加密**单个文件上限 64 MB，超了会拒绝写入；大文件断点续传还没做。

## 免费、隐私与我们不做的事

- **协议**：本软件以 Apache-2.0 协议发布，个人和公司都可以免费使用。安装包与校验值只在本仓 [GitHub Releases](https://github.com/kingaiwork/Wenshu-Releases/releases) 与官网发布。
- **隐私是机制，不是口号**：文件默认只保存在你绑定的文件夹或网盘里，我们没有服务器，也看不到你的任何文档；崩溃报告要不要发送，由你手动决定。
- **不做清单**：不要求注册账号；不提供官方云；不收集遥测数据；不在文档里放广告；没有会员版，没有功能锁，也没有试用到期。
