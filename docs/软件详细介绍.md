# 文枢 WENSHU 软件详细介绍

## 这是什么

文枢是一套装在桌面上的办公软件，一个应用里放了四个入口：Writer 文字、Calc 表格、Impress 演示、PDF 工具箱。它按 Apache-2.0 协议开源，个人和公司都免费，没有会员版，没有功能锁，也没有试用到期这一说。

它和大多数办公软件最大的区别在数据：文枢没有官方云，没有账号系统，打开就能用。文档存在你本地的文件夹里，那是唯一的真源；想跨设备同步，你在设置里绑一个自己的存储（本地文件夹、系统云盘同步文件夹、WebDAV），软件把文件同步过去，服务器是谁的、数据在哪，全由你决定。崩溃报告默认不发送，要不要发由你手动点。

当前版本 v0.1.0，是未签名的公开测试版，Windows 和 macOS 都有安装包。先在这里把话说全：它还在测试期，下面的「当前限制」一节列了已知的短板，介意的话可以等后面的版本。

技术构成一句带过：桌面壳 Tauri 2，界面 React，编辑器用 Univer 开源版，文件格式读写是我们自研的通道，PDF 加密等重活在 Rust 侧。安装包不大，内存占用压得住，这是这套组合的直接好处。

## Writer 文字

写文档的入口，docx 走自研通道打开和保存。

日常文档该有的它都有：段落、标题层级（Heading 1–6）、粗斜下划线删除线、字号字色、高亮底纹、对齐、行距段距、缩进、列表（含多级编号）、表格（合并单元格、底纹、行高、嵌套表）、超链接、图片、分页分节、页大小和页边距。脚注、尾注、批注、域（目录、页码、日期这类）也都在通道层做了保真处理：打开别人的文件再存回去，这些东西不会在往返里丢掉。

实测口径（开发期台架，语料为 60 份合成 docx 测试文件，下同）：往返后正文字符零丢失，表格 17/17、图片部件全保留；脚注尾注条目与正文引用位置逐项对得上；批注的作者、文本和锚定位置都保住了。

有三条边界要讲清楚：

- 文档里的文本框，打开后会变成普通段落。文字一字不少，但框的位置、环绕和样式没了，介意版式的要在 Word 里重排。
- 公式（OMML）会抽成普通文字，根号、分式这些结构和排版保不住，需要公式的文档请回 Word 处理。
- 浮动环绕的图片、注音、分栏设置、书签，文件往返都能原样带回，但编辑器画布上按简化形态呈现（图片按行内图显示、注音只显基字、分栏仍按单栏排）。文件不丢东西，画布上看到的不是最终版式，拿不准时用兼容模式看 PDF 最稳妥。

碰上排版特别复杂、或者自研通道吃不准的文档，Writer 有兼容模式：调用你本机装的 LibreOffice 把文档转成 PDF 预览，先保证看得全、转得出，不硬撑着编辑到走样。兼容模式需要本机装有 LibreOffice，软件会自动找它（找不到会在界面上明示）。

### 公文模块

Writer 里单独有一个「公文」入口，针对 GB/T 9704-2012 党政机关公文格式做了两件事：

- 一键套版：识别出发文机关标志、发文字号、标题、主送机关、正文、三级标题、附件说明、落款、成文日期、版记等 11 类要素，按国标参数（A4、边距、版心、22 行×28 字、字号字体）套好。识别把握不大的要素会先弹出来让你确认，不确认不动手。套版前的原稿留有副本，一键回滚，回滚结果与原文逐字节一致（实测）。
- 公文体检：28 条规则逐条查（页面、标题、正文字体字号、页码格式、成文日期写法、发文字号括号、错别字词库等），给出通过/命中/需人工确认/不适用四种状态，命中项标出在哪一段。开发期实测：合规样本误报 0，故意注入的 22 处错误全部抓到，其中 14 处实测可一键修复并复检通过。有几条规则（页码距版心距离、红色分隔线、标题回行断句）靠文件数据判不了，面板里如实标成「人工确认」，不会假装查过。

要注意：公文模块不打包任何字体文件，只写字体名。你电脑上没有仿宋、方正小标宋这些字体时，显示和打印效果以你本机字体为准。

## Calc 表格

电子表格入口，xlsx 走自研通道。公式在本地计算，编辑器是 Univer 开源版的表格引擎。

能做的：多工作表、值与公式、合并单元格、冻结窗格、隐藏表、定义名称（命名区域）、基础样式（字体、字号、粗斜、字色、纯色填充、对齐、数字格式、日期）。公式函数方面，开发期做过 100 个常用函数的对拍：以 LibreOffice 为参照，严格口径 90.0% 一致；把参照本身的口径偏差剔掉后是 97.9%。剩下的差异多数是两边引擎对个别函数的口径分歧，已经逐条立案，不是算错了没人管。

大表有专门的打开路径：文件达到 5 MB 或预估行数超过 2 万，自动走流式解析加延迟计算，状态行会明示走了哪条路，你也可以在「打开模式」里手动选自动/完整/快速。开发期实测（同一台开发机、带缓存值的十万行文件）：打开中位约 4.3 秒；改一个格子的增量重算，引擎补丁后中位约 21 毫秒。这两个数是开发机的台架结果，你的机器上会有出入，不当成保证写。

延迟计算有个配套的保险：公式还没回填完就点保存会丢公式，所以这种状态下保存会被拦住，先触发计算、算稳了再让存，不会让你静默存出一份没有公式的残表。

边界，照实说：

- xlsx 里的图表目前不进编辑器，打开时会被剥离并登记，保存后图表回不来。带图表的工作簿，先用兼容模式看，或者别在文枢里点保存。
- 数据透视表不一样：透传保住了。在文枢里打开带透视表的文件再存回去，透视部件 5/5 原样带回，用 Excel 或 LibreOffice 打开仍是活透视，总计数字对得上（实测）。但你在文枢里改了源数据，透视结果要回 Excel/LO 里刷新缓存才跟随，文枢自己不重算透视；编辑器里新建透视表目前也不支持。
- 条件格式、数据验证、单元格边框、行高列宽、打印设置和筛选状态目前不随通道往返，打开保存后会丢。数字和公式本身不受影响。
- 单元格里的多段富文本会合成纯文本，分段格式丢；超链接只保文字、丢地址。

## Impress 演示

做幻灯片的入口，pptx 走自研通道，有两个打开方式：「打开 pptx（编辑）」真导入进编辑器，「打开 pptx（兼容查看）」经 LibreOffice 只看不改。

编辑通道能处理：页面顺序与尺寸、隐藏页、文本框和占位符文字、run 级样式（字体、字号、粗斜、字色、对齐）、形状（预设几何、纯色填充、边框、形状内文字）、图片、页面纯色背景。开发期实测（40 份合成 pptx 语料）：往返页数、元素计数、文本字符三项全部 100% 对上，备注页 12/12 保留。

这个入口比前两个年轻，短板也最明显，先讲在前面：

- 编辑模式打开外部 pptx 目前不稳定：实测出现过导入后编辑器白屏。重要稿子先用「兼容查看」打开看版式，别直接进编辑。
- 占位符继承自版式的几何位置没有解析，编辑器里给的是按类型估的默认框，位置和原版式会有出入。文件往返不受影响，画布上看着不准。
- 表格帧、图表、SmartArt、视频音频、切换效果、动画时间轴走透传：文件里原样保留、存回去还在，但编辑器里不显示、不能改。
- 编辑器内对导入演示的实际渲染手感，还没有完成真机截图验收。打开复杂稿子拿不准，就先走兼容查看。

## PDF 工具箱

PDF 查看器加一组本地小工具，全部在本机处理，文件不出电脑，处理结果另存为带后缀的新文件，永不覆盖原件。工具箱已经落地的工具（开发期自测 16/16 通过）：

- 合并：按列表顺序把多个 PDF 合成一个。提醒一句：原文件的书签（大纲）跨文档合并不了，源文件带书签时结果区会黄字明示，不装作保住了。
- 拆分：按页码规格分段导出，如 `1-3,4-6` 每段一个文件。
- 提取页面：按规格抽出页面合成一个新文件。
- 删除页面：删指定页；要删全部页会直接报错拒绝，不产空文档。
- 旋转页面：90/180/270 度，可指定页或全部页。
- 压缩：只做结构层面的压缩（对象流打包、冗余对象清理）。图片重采样做不到，界面上就写明实际手段和体积变化，不设假档位。
- 文字水印：内容、字号、透明度、旋转、平铺或居中，可指定页。中文水印用的是阅读器字体替代路线，主流阅读器（Acrobat、Edge、福昕、macOS 预览）能正常显示；极简阅读器上中文水印可能缺字，文字本身可抽取可检索，界面里有明示。
- 图片水印：PNG 嵌入，保透明通道，设置项同文字水印。只收 PNG。
- 页码：四种式样（第 N 页 / N / 第 N 页·共 M 页 / —N— 公文式），位置六选，可设起始页码。
- 页眉页脚：页眉页脚各左中右三段自定义文字，任意组合。
- PDF 转图片：逐页渲染 PNG，可选 1x/2x/3x，打包成一个 zip。
- 文件信息：页数、页面尺寸分布、文件大小、版本、是否加密、标题作者等元数据，读不到的字段如实留空。
- 加密（桌面版）：给 PDF 设打开密码，算法是 AES-256（PDF 2.0 标准安全处理器 R6），开发期用 poppler 的 pdfinfo 交叉验过，权限位（打印 yes、复制 no、编辑 no）与登记一致。打开密码和权限密码可分开设，三项权限（打印/复制/编辑）可勾选，默认只放打印。已加密的文件拒绝重复加密，输出路径和原文件相同会拦下，不覆盖原件。这个功能只在桌面版里有，网页版界面上整区禁用并写明原因。

## 数据与同步：绑你自己的存储

这是文枢最不一样的一块，单独说细一点。

### 绑定与真源

在设置页的存储区里绑定：本地文件夹、WebDAV（坚果云、Nextcloud、群晖都走这条）、或者你系统云盘的同步文件夹（本质也是本地文件夹）。桌面版绑定本地文件夹是把路径授权给应用，重启不用重选；WebDAV 要填服务地址和账号、应用密码，设置页有「测试连接」可以先验通不通。

规矩只有一条：本地文件永远是真源，绑定的存储是镜像。同步失败、断网，都不挡你本地编辑，失败的项进队列退避重试，网络恢复后自动补传。解绑只清本机这边的配置和凭据，不会去删远端文件。

WebDAV 的应用密码在桌面版里只存操作系统钥匙串（Windows 凭据管理器 / macOS 钥匙链），不进配置文件明文。早期版本存在本地的混淆条目，升级后首次用到凭据时会自动迁进钥匙串并回读校验，迁不成就不删旧的。

### 两台设备同改一份文件

同步发现两边都改了同一份文件，不覆盖任何一边：远端那版会落成一份冲突副本，命名形如「文件名（冲突副本·设备名·日期时间）」，两份都在，台账里标成待裁决。你在设置页的「冲突待解决」区里处理，每条冲突并排着两版的大小和修改时间，三个选择：

- 用我的版本：对方那版先归档进版本历史，再拿本地版更新远端。
- 用对方版本：本地这版先归档，再拿远端版覆盖本地正本。
- 两份都留：冲突副本改个名转成普通文件，之后当独立文件正常同步。

任何一步失败，冲突记录都留着，错误写在条目下面，不会假装处理完了。落败的那一版去哪了也有交代：进版本历史。

### 版本历史

每次往远端上传新版之前，远端现版会先归档到你绑定存储的 `.wenshu/history/` 目录里，每份文件保留最近 30 版，最旧的自动淘汰。改坏了、裁决选错了，都能去那里把旧版捞回来。历史存在你自己的存储里，不占什么官方空间，因为根本没有官方空间。

### 客户端加密（可选）

怕文件放在网盘上不踏实，可以给某个绑定开客户端加密：内容在本机用 AES-256-GCM 加密之后才写出去，读回来自动解密。密钥由你的口令经 PBKDF2-HMAC-SHA-256（60 万次迭代）派生，每个文件独立随机数，格式是公开写死的自描述格式（WSE1），用独立实现交叉解开验过，不靠保密格式锁人。

四件事必须先说清：

- 只加密内容，文件名保持明文，方便你在服务商后台辨认文件。别对文件名有隐私预期。
- 口令丢了就是丢了。没有后门，没有找回，远端的密文永远解不开。设置页开加密时这句话写在最前面。
- 口令可以勾选「记住在本机」，那样存进操作系统钥匙串；不勾，每次启动应用后第一次同步前要输一次解锁。
- 本程是整文件加解密，单个文件上限 64 MB，超了直接拒绝写入、远端不留残件。分片流式加密还没做。

错口令、密文被改过任何一个字节，解密都会失败并报错，绝不拿坏数据写回覆盖远端原件。

### 同步的已知缺口

- WebDAV 目前只在本机回环的测试服务（wsgidav）上全链验过。坚果云、Nextcloud、群晖三家的真实服务还没逐家实测，各家 ETag 语义和目录查询的怪癖可能带来兼容问题，设置页不会把没验过的标成「已验证」。这是当前最实在的一块短板。
- 大文件断点续传没做；远端变化靠同步时扫描发现，没有实时推送。
- 软锁：同一文件被另一台设备占用编辑时，锁标记会拦住第二台并报错；锁超过 120 秒没心跳可以接管，接管会留痕。

## 隐私与免费

再重复三件具体的：不注册账号；没有默认遥测，不往任何服务器发使用数据，崩溃报告要发你手动发；你的文档只出现在你的电脑和你亲自绑定的存储里。协议是 Apache-2.0，个人和公司都免费使用；安装包经官方下载仓发布，每个版本附 SHA-256 校验值可核对。

## 系统要求与当前限制

系统要求：Windows 或 macOS 桌面系统，从 GitHub Releases 下载对应安装包（Windows 有 exe 安装版和 msi，macOS 有 dmg）。窗口最小 960×600。兼容模式需要本机另装 LibreOffice。用到 WebDAV 同步、钥匙串这些功能的具体系统版本下限，随版本在 Release 页说明里给出，这里不写没验过的数字。

当前限制汇总（v0.1.0，除上文各节已说的，再集中列一遍）：

- 未签名：没有代码签名证书，Windows 安装时 SmartScreen 会拦，macOS Gatekeeper 会拦，过法见使用手册。Release 页附 SHA-256 校验值，建议对完再装。
- Writer 画布验收未完：文档里的图片在编辑器内的显示、列表符号渲染，受开源版编辑器能力所限，文件往返实测无损，但编辑器内呈现没有宣称达标，以真机验收为准。
- Impress 最年轻：编辑打开外部 pptx 不稳定（可能白屏）、占位符位置近似、表格图表透传不显示、渲染手感未做截图验收。
- xlsx 图表往返丢失；条件格式、数据验证、边框、行高列宽不往返（见 Calc 节）。
- docx 硬边界两条：文本框拍平保文字、公式抽成纯文字（见 Writer 节）。
- WebDAV 真实服务商未逐家实测；加密单文件上限 64 MB；大文件无断点续传。
- 性能数字（十万行打开约 4.3 秒、增量重算约 21 毫秒、公式函数严格口径 90.0%）都是开发期在开发机上用合成语料测的口径，写出来是给行内人留个实测底子；换台机器、换份文件，结果会有出入，别拿它当对每台机器的承诺。
