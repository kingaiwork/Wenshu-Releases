# 文枢 WENSHU 版本更新记录

文枢目前只有一个对外版本线：v0.1.0 公开测试版。测试期里安装包以草案（draft）形式滚动更新，下面按草案顺序记，每条都是实际进了包的变化。再往前是打包之前的开发里程碑，单独列在最后，让你能看清这个软件是怎么长起来的。

安装包均为未签名测试版，Windows（exe / msi）与 macOS（dmg）双平台，Release 页附 SHA-256 校验值。

---

## v0.1.0-draft.5（2026-10-28）

扩展五线合入后的构建。同日上线公开下载仓 Wenshu-Releases 发布本版安装包；源码仓保持私密，公开的只有安装包与文档。

- **暗色模式接通**：顶栏可切换深/浅色，跟随系统或手动选定后记住；四入口主题色在暗色下提亮处理。用了一阵子的深色令牌这版才真正接上开关。
- **最近文档开始记了**：四个入口的打开、保存、兼容打开、工具箱产出都会登记到首页最近文档，同名去重、上限 20 条，只存本机。
- **冲突可以在应用里裁决**：以前同步冲突只生成冲突副本，要你去文件层自己处理；现在设置页有「冲突待解决」区，两版信息并排，三种处理（用我的 / 用对方的 / 两份都留），落败版自动进版本历史，处理失败留记录报错。
- **自绑存储客户端加密**：按绑定可选开启，内容在本机用 AES-256-GCM 加密后再写到你的 WebDAV，口令经 PBKDF2（60 万次迭代）派生，文件名保持明文。口令丢失无法恢复，启用界面有明示。单文件上限 64 MB。
- **数据透视表不再丢**：查出一个真问题——xlsx 打开保存一轮，透视表部件曾被静默丢掉。现在透视部件整包透传，往返后 5/5 齐全，用 LibreOffice 打开仍是活透视、总计对得上；同时补了两份原生透视语料进回归测试。
- **docx 降级清单收尾**：开工时登记的 14 类降级逐类处置完——10 类已修复（修订标记、注音、分栏、书签、上下标、字符样式、行内内容控件、软回车、浮动图片透传、节断结构），2 类转保真透传（扩展批注部件、文档设置与主题等辅助部件原样带回），剩下 2 类定为硬边界并写进说明：文本框打开后拍平为普通段落（文字不丢、版式丢），公式抽成纯文字。另外查清一件事：此前立案的「拼音注音疑似降级」是 LibreOffice 24.2 不渲染注音造成的假象，误报销案。

## v0.1.0-draft.4（2026-10-21）

Tauri 桌面里程碑三件合入的构建。

- **本地文件夹绑定走桌面桥**：桌面版绑定本地文件夹改为 Rust 侧授权（填路径授权、跨重启免重选），文件操作只允许在授权根目录内进行，路径穿越和符号链接逃逸在 Rust 侧逐次校验拒绝。网页版仍走浏览器目录授权，两种形态语义一致。
- **LibreOffice 侧车自动拉起**：兼容模式不再需要你手动起服务。桌面版自动按「环境变量指定 → 系统路径 → 常见安装位置」的顺序找 LibreOffice，每次转换用一次性独立配置目录，120 秒超时。找到的第一个实测版本是 24.2.7.2，本机端到端转出过有效 PDF。
- **PDF 加密上线（桌面版）**：工具箱新增「加密（桌面版）」区，Rust 侧 lopdf 实现，AES-256（R6）给 PDF 设打开密码，打开/权限密码可分设，打印/复制/编辑权限可勾（默认只放打印）。已加密文件拒绝重复加密，同路径拒绝覆盖。用 poppler 的 pdfinfo 交叉验过算法与权限位。

## v0.1.0-draft.3（2026-10-20）

新图标、新界面、凭据进钥匙串的构建。

- **界面设计升级**：全应用样式收敛到一套设计令牌（品牌色印红 #9E2B25、墨纸暖灰、四入口各自主题色、字阶间距圆角成体系），组件里散落的硬编码颜色和字号清零。首页重做：四张自绘图标入口卡片加状态徽标，最近文档空状态做了正式设计。
- **品牌定版**：应用图标采用印章演进方案（A），页眉字标采用现代组合方案（D），品牌红统一 #9E2B25，旧红色值全仓退役。
- **WebDAV 凭据迁进操作系统钥匙串**：应用密码不再以混淆形式存本地配置，改存 Windows 凭据管理器 / macOS 钥匙链（keyring）。旧条目首次使用时自动迁移：先写钥匙串、回读校验一致了才删旧的，迁不成保留旧数据下次再试。设置页在钥匙串模式下显示绿色说明，非桌面环境回退时继续红字明示那是混淆不是加密。

## v0.1.0-draft.1（2026-10-20）

第一个桌面草案包。此前所有能力在这个包里第一次凑齐：四入口编辑器、自研 docx/xlsx/pptx 通道、兼容模式、公文模块、PDF 工具箱两批工具、自绑存储同步原型。发布流水线在这一版改为经 GitHub Release 草案发附件（原来的构建附件通道撞了账号配额）。

## 打包之前的开发里程碑

### 2026-10-18 · 大表性能攻坚收尾

- 十万行 xlsx 的流式打开做了两项优化（解析器零切片化、实体解码改手写扫描器，同窗 A/B 导入耗时降 35.2%）。独占环境按标准口径复测：带缓存值的十万行文件打开中位 4,263 毫秒，进了 5 秒线。
- 公式增量重算的根因钉死在引擎每次执行全量重建依赖图上，三个补丁点（各自可独立开关）落地后端到端中位 21 毫秒，进了 200 毫秒线。两个数都是开发机台架口径。
- 顺带定案：编辑器引擎从 1.0.4 升 1.1.0 的评估做过，新版没修重算根因，并入后续例行升级，不单独为它发版。

### 2026-10-17 · 首批能力成型（多线并行，一天内）

- **应用骨架与 PDF 查看**：Tauri 桌面壳、四入口导航、PDF 查看器（pdfjs）接通。
- **兼容语料与评分管线**：合成测试语料补齐到 180 份（Writer 60 / Calc 80 / Slides 40），LibreOffice 参照渲染 180/180 成功，公式对拍 189/193（4 处是参照引擎自身的缺口），五维评分（内容/公式/对象/版式/往返）跑通，确认的内容丢失为零。100 个常用函数的专项对拍同日完成：严格口径 90.0%，剔除参照口径偏差后 97.9%。
- **xlsx 通道 v1**：导入导出对拍，单元格 151/151、公式 28/28、公式计算值经 LibreOffice 重算 28/28 一致。修了三个真问题：含图表文件读取崩溃（剥离图表部件重试并登记降级）、以等号开头的文本被当成公式吞字、命名区域丢失导致公式算错。边框、条件格式等 12 类降级逐项登记。
- **docx 通道 v1 与第二批**：导入导出往返跑通 60/60，正文字符保留 99.98%，公文份的页脚页码靠部件透传往返成功。同日第二批把脚注、尾注、批注、域四类从降级名单里关闭（改为通道层保真：文件里原样带回，编辑器里不显示不可改），全部件字符保留升到 99.98%。
- **pptx 通道 v1**：往返 40/40，页数、元素、文本三项 100%。占位符几何近似、图表与表格透传等降级逐项登记。
- **公文模块 v1**：按 GB/T 9704-2012 做套版引擎（11 类要素识别，低置信先确认，原稿可逐字节回滚）和 28 条体检规则（22 条自动判定、4 条部分自动、2 条人工确认）。实测：合规语料误报 0，注入的 22 处错误全抓，一键修复实测 14 项全部修后复检通过。
- **PDF 工具箱两批**：第一批合并、拆分、提取、删除、旋转、结构压缩，自测 8/8；第二批文字/图片水印、页码（四式，含 —N— 公文式）、页眉页脚、转图片、文件信息，自测累计 16/16。合并丢书签、压缩只做结构层、水印中文字体走阅读器替代，这三处限制当时就写进了界面说明。
- **自绑存储同步原型**：WebDAV 与本地文件夹两类提供者、同步引擎（哈希台账、条件写、指数退避）、软锁、冲突副本、远端 `.wenshu/history/` 30 版历史，在本地测试服务上 8 个场景自测全过。同时如实登记了缺口清单——凭据存储、文件夹授权持久化、冲突裁决界面、客户端加密、真实服务商矩阵，都在后面的草案版本里逐项销掉（见 draft.3 / draft.4 / draft.5）。
- **LibreOffice 侧车封装**：headless 转换的命令行与本地服务两种形态封装完成，兼容模式的转换链路打通（当时还要手动起服务，draft.4 改为桌面版自动拉起）。
