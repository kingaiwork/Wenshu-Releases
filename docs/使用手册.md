# 文枢 WENSHU 使用手册

版本对应 v0.1.0（未签名公开测试版）。这份手册按「照着做」的顺序写：先装上，再打开文档，然后是绑存储、处理冲突、开加密这些进阶项。最后是常见问题。

## 快速开始（5 步）

1. **下载并安装**：系统弹警告时，按第一章的点法放行一次，只弹这一次。
2. **打开文枢**：从首页进任意一个入口，新建一份，或打开你的第一个文档（第二章）。
3. **打开一份已有的 Word / Excel 文件**：试着改一点再存回去，看看往返效果（第三、四章）。
4. **绑你自己的存储**：本地文件夹或 WebDAV，让文件能在两台设备之间同步（第七章）。
5. **重要的文件再往前一步**：开客户端加密防人看，改坏了去版本历史里捞旧版（第八、九章）。

## 一、安装

安装包在文枢公开下载仓的 Releases 页面（https://github.com/kingaiwork/Wenshu-Releases/releases/tag/v0.1.0）：Windows 有 `.exe` 和 `.msi` 两种，选一个即可；macOS 是 `.dmg`。同一页面附了 SHA-256 校验值，建议装之前先对一遍。

校验方法：

- Windows：打开 PowerShell，运行 `Get-FileHash .\下载的文件名 -Algorithm SHA256`，把输出和 Release 页上的值对一下。
- macOS：打开终端，运行 `shasum -a 256 ~/Downloads/下载的文件名`。

这个版本没有代码签名证书，两个系统第一次装都会拦一下，这是预期现象，过法如下。

### Windows

1. 双击 `.exe`（或 `.msi`）开始安装。
2. 弹出 SmartScreen 蓝色提示「Windows 已保护你的电脑」时，点「更多信息」。
3. 出现「仍要运行」按钮，点它，安装继续。
4. 装完从开始菜单打开「文枢 Wenshu Office」。

### macOS

1. 打开 `.dmg`，把文枢拖进「应用程序」文件夹。
2. 第一次打开会被拦下，提示无法验证开发者。关掉这个弹窗。
3. 打开「系统设置 → 隐私与安全性」，往下拉，找到刚才被拦的那条，点「仍要打开」。
4. 也可以在「应用程序」里右键点文枢，选「打开」，弹窗里再点一次「打开」。

介意未签名提示的话，可以等签名版本再装。

## 二、首次打开

打开应用就是首页：上面四个入口卡片（Writer 文字、Calc 表格、Impress 演示、PDF），下面是最近文档。没打开过任何文件时，最近文档区是空的，显示引导文案，这正常。

几点先熟悉的：

- 首页右上角有主题切换按钮，可以在浅色和深色之间换。第一次启动跟随你系统的明暗设置，手动切过以后记住你的选择。
- 文档纸面始终是白的，深色模式只变应用外壳，这是刻意的，方便你判断打印效果。
- 不用注册，不用登录，没有任何一步要你联网。断网状态下除同步外全部功能照常。

## 三、Writer 文字

### 打开和保存 docx

1. 首页点「Writer 文字」进入。
2. 点「打开 docx」，选文件。打开成功后，这份文件会登记到首页的最近文档。
3. 编辑完点「保存为 docx」，导出一份 docx。建议先另存，不要直接冲掉原件——通道虽然经过往返实测，公文页脚、脚注批注这些都能带回，但留一份原件是稳妥习惯。

### 打开的文档看起来不对时

文档特别复杂（大量文本框、浮动图片、分栏）时，编辑器里的样子可能和 Word 里不一样。文件本身没坏，是画布呈现简化了。这种情况：

1. 回到 Writer，改用「兼容模式」打开同一份文件。
2. 兼容模式调用你本机的 LibreOffice，把文档转成 PDF 给你看，版式以那边为准。
3. 兼容模式只看不改。要改，回 Word 或者接受编辑器形态后再改。

前提：兼容模式需要电脑上装有 LibreOffice（免费，官网可下）。没装时界面会明示找不到，不会假装打开成功。

### 公文：套版和体检

处理党政机关公文（GB/T 9704-2012）时用 Writer 工具栏上的「公文」入口：

1. 先打开 docx，再展开公文面板。
2. 点「公文体检」：28 条规则逐条出结果，通过、命中、需人工确认、不适用分开列，命中的会标出在哪一段。标「人工确认」的几条（比如页码距版心的距离）软件判不了，需要你自己核。
3. 命中的条目里，带「一键修复」的可以直接点修复，修完会自动复检。
4. 要整篇套版，点「一键套版」。软件先识别发文机关标志、发文字号、标题、主送机关、正文、落款这些要素；把握不大的要素会列出来让你先确认，确认了才动手。
5. 套完不满意，点「回滚」，回到处理前的样子。回滚件和原稿逐字节一致，套版前请放心。
6. 最后照常「保存为 docx」导出。套版重建的国标页脚（—N— 页码）会随导出带出。

提醒：软件只写字体名，不带字体文件。仿宋、方正小标宋这类字体你电脑上没有的话，屏幕显示会用替代字体，打印前请在有字体的机器上确认一遍。

## 四、Calc 表格

### 打开和保存 xlsx

1. 首页点「Calc 表格」进入，点「打开 xlsx」选文件。
2. 大文件会自动走快速通道：文件超过 5 MB 或行数很多时，状态行会写明「走流式解析＋延迟计算」，这是正常提示。
3. 延迟计算状态下，表格上方有徽标「公式待计算（N 条）」。先看数据没问题，数值是文件里存着的缓存值；想让公式真算，点「立即计算」，徽标变成「计算中」，算完自动消失。
4. 这个状态下第一次改单元格，会弹一次提醒：你改的数是基于缓存值的。要接着改就点「暂不」，要先算就点「立即计算」。
5. 保存点「保存 xlsx」。公式还没算完时保存会被拦下来，先触发计算再让你存——这是专门防你把公式存丢的设计，别当成故障。

「打开模式」可以手动选：自动（默认）、完整（小文件也走全样式通道）、快速（强制流式＋延迟）。日常保持自动就行。

### 三个先知道的坑

- 表格里有图表的，先别在文枢里保存。图表目前进不了编辑器，打开时会被剥离，存回去就没了。看图表用各页面的「兼容模式」打开（Calc 入口同样有，经 LibreOffice 转 PDF 看）。
- 数据透视表可以放心打开保存，透视会原样带回，Excel 里打开仍是活的。但你在文枢里改了源数据，透视数字不会跟着变，回 Excel 刷新一次缓存才更新。
- 条件格式、下拉验证、边框、行高列宽，打开保存后会丢。数字、公式、合并、冻结窗格、命名区域都保得住。

## 五、Impress 演示

1. 首页点「Impress 演示」进入。
2. 两个打开入口分清楚：「打开 pptx（编辑）」是真导入进编辑器改；「打开 pptx（兼容查看）」是经 LibreOffice 看版式，只看不改。
3. 编辑完点「保存为 pptx」导出。
4. 先知道两点：占位符的位置在编辑器里是估算框，和原版式有出入，排版精细的稿子以兼容查看为准；表格、图表、动画、切换效果在编辑器里不显示，但文件里都在，保存后用 PowerPoint 打开还是完整的。

## 六、PDF：查看与工具箱

### 看 PDF

首页点 PDF 入口（或「打开 PDF 文件」），选文件即可阅读。在工具箱里处理过的文件、打开过的文档，都会登记到首页最近文档。

### 工具箱通用操作

1. 进 PDF 页，切到「工具箱」标签。
2. 把 PDF 添加进文件列表（点添加或直接拖进去），可以多选、排序、移除。列表里点选一行，就是当前要处理的单个文件。
3. 选工具、填参数、执行。结果出现在结果区，点下载保存。
4. 规矩：所有处理都另存新文件，文件名带后缀（如 `-合并`、`-水印`），永不覆盖原件。某个文件损坏只会在它那一行标错，不影响其他文件。

### 各工具怎么填

- 合并：列表顺序就是合并顺序，先排好序再点合并。原文件带书签的，合并后书签保不住，结果区会黄字提示。
- 拆分：页码规格按段写，如 `1-3,4-6`，每段导出一个文件。
- 提取页面：规格如 `1-3,5,8`，抽出的页合成一个新文件。
- 删除页面：填要删的页，如 `2,5-7`。全部删光会被拒绝报错。
- 旋转页面：选角度（90/180/270），可指定页或全部页。
- 压缩：直接执行。说明里会写清实际用了什么手段、体积变了多少。只有结构压缩，图多的文件压不动多少，这是实话。
- 文字水印：填内容，调字号（6–200）、透明度、角度；选平铺满页或单个居中；指定页就填页码规格，不填是全部页。
- 图片水印：选一张 PNG（只收 PNG），其余同上。
- 页码：选式样（第 N 页 / N / 第 N 页·共 M 页 / —N—），选位置（页眉或页脚的左中右），需要的话改起始页码。
- 页眉页脚：页眉、页脚各有左中右三段文字，填哪段出哪段，全空会报错。
- 转图片：选倍率（1x/2x/3x），逐页渲染成 PNG 打包下载一个 zip，里面是 `原名-第N页.png`。
- 文件信息：选中文件点查看，页数、尺寸、是否加密、标题作者这些都在面板里，读不到的字段留空。

### 给 PDF 加密（只有桌面版）

1. 在工具箱的「加密（桌面版）」区，填输入文件路径；输出路径可以留空，自动生成 `原名-加密.pdf`。
2. 打开密码输两遍，必须一致，空密码会被拦。
3. 权限密码可留空，留空就和打开密码相同。
4. 权限勾选默认只有打印。想让对方能复制文字、能改，就把对应项勾上。
5. 点加密。成功后密码输入框自动清空。密码不存任何地方，忘了没法帮你找回。
6. 注意：已经加密过的文件不能再加密（会报错）；输出路径和原文件填成同一个也会拦，这是防覆盖原件。

加密算法是 AES-256，对方用 Acrobat、Edge、福昕这些主流阅读器输密码就能打开。

## 七、绑你自己的存储（同步）

想在两台设备之间同步文档，或者给文档留个异地副本，按下面做。先提醒：本地文件永远是主本，绑定存储只是镜像，同步出问题不会伤本地文件。

### 准备

- 桌面版应用，两台设备各装一份。
- 一个你自己的存储：另一台电脑能访问的文件夹、系统云盘的同步文件夹，或者一个 WebDAV 服务（坚果云、Nextcloud、群晖 NAS 都提供 WebDAV）。
- 用 WebDAV 的话，先在服务商那边准备好服务地址、账号和应用密码。坚果云是在网页端「账户信息 → 安全选项」里生成应用密码，别拿登录密码直接填。

### 绑定步骤

1. 打开设置页，进「存储」区（路由是设置里的存储页）。
2. 先填这台设备的设备名，起个能认出来的名字，比如「家里台式机」。冲突副本的文件名里会带它，日后对账靠它。
3. 选绑定方式：
   - 本地文件夹（桌面版）：填文件夹的绝对路径，点授权并绑定。这个授权跨重启有效，不用每次重选。
   - WebDAV：填服务地址、账号、应用密码，保存。
4. 点「测试连接」，通了再往下。报鉴权失败（错误码 4101）多半是应用密码不对，回去重生成一个。
5. 点「立即同步」跑第一轮。全量扫描要算哈希，文件多时第一轮慢一点，之后只传改动。
6. 在第二台设备上重复以上步骤，绑同一个存储。两台都同步完，文件就对齐了。

日常使用中同步自动按队列跑，断网时失败项排队退避，网络恢复自动补传。设置页能看队列和每一项的状态；要停就点「暂停」，恢复点「继续」。

### 版本历史在哪找

每次上传新版前，旧版会被归档到绑定存储的 `.wenshu/history/` 目录下，按文件分文件夹存时间戳版本，每份文件留最近 30 版。改坏了文件，去那里按时间找上一版，下载回来即可。

### 解绑

设置页里点解绑，会弹确认框：解绑只清掉这台设备上的绑定配置和存着的凭据（包括记住的加密口令），不会删远端任何文件。放心点。

## 八、冲突了怎么办

两台设备在没同步的间隙里改了同一份文件，下一次同步就会产生冲突。软件的处理是：不覆盖任何一边，远端那版落成一份冲突副本（文件名形如「报告（冲突副本·家里台式机·20261021-0930）.docx」），原文件保持你本地的样子，台账标记待裁决。

处理步骤：

1. 打开设置页的存储区，有冲突时会出现「冲突待解决」区，逐条列着。
2. 每条并排显示两版的信息：你的版本（设备名、大小、修改时间）和对方版本（大小、修改时间）。先想清楚哪版是你想要的正本。
3. 三个按钮选一个，点了会先弹确认框说明后果：
   - 用我的版本：对方那版先存进版本历史，再把你本地这版同步为正本。适合「我这台上改的才是对的」。
   - 用对方版本：你本地这版先存进版本历史，再拿对方版覆盖本地正本。适合「另一台上改得更新」。
   - 两份都留：冲突副本改名为「原名（对方版·时间）」变成一份普通文件，以后独立同步。两版内容都要留着慢慢合并时选这个。
4. 处理成功条目自动消失。处理失败会红字写明原因，条目留着，修好问题（比如网络恢复）再点一次即可。
5. 选错了也不怕：落败的那版在 `.wenshu/history/` 里，去捞回来。

小提示：拿不准就选「两份都留」，先把两版都保住，回头在编辑器里人工合并，比选错正本再捞历史省事。

## 九、给同步内容加密

适合文件要经过网盘、又不想让服务商看到内容的场景。按绑定开启，本地文件始终是明文，只有写到远端的那一份加密。

1. 打开设置页存储区，找到目标绑定的卡片，进加密区。
2. 先把说明读完，重点两句：只加密内容、文件名是明文；口令丢失无法恢复，没有后门。
3. 设置口令，点启用。软件会用远端的一个文件试解密来验口令对不对。
4. 决定要不要勾「记住在本机」：勾上，口令存进操作系统钥匙串，下次自动解锁；不勾，每次启动应用后、第一次同步之前，要在设置页输一次口令解锁。不解锁时同步会报一个引导错误（4504），照提示输口令即可。
5. 之后正常同步。去服务商后台看，文件内容是密文（WSE1 格式），文件名照旧能认。
6. 换设备时，在新设备上绑同一存储、开加密、输同一个口令，就能读回。口令不同会直接报解密失败（4502），不会写坏远端文件。

限制：单个文件上限 64 MB，超了会拒绝写入并报错，远端不会留半截文件。大文件先别开这个绑定的加密。

## 十、常见问题

**我安装时被系统拦下来了，说无法验证，正常吗？**
正常。v0.1.0 没买代码签名证书，Windows 的 SmartScreen 和 macOS 的 Gatekeeper 都会拦。过法见第一章。不放心就先校验 SHA-256，或者等签名版。

**我打开 docx，版式和 Word 里不一样，是不是文件坏了？**
多半没坏。复杂排版（文本框、浮动图、分栏）在编辑器里是简化呈现。用「兼容模式」打开看 PDF，版式以那个为准。文件往返保存的保真度有实测托底，丢内容的情况极少，两个已知的硬伤是文本框变普通段落、公式变纯文字。

**我把表格存回去，图表怎么不见了？**
这是当前已知限制：xlsx 的图表进不了编辑器，打开时剥离，保存后回不来。带图表的工作簿别在文枢里点保存；要看，用 Calc 的兼容模式转 PDF 看。

**我存回去的透视表还能用吗？**
能。透视部件原样带回，Excel 打开仍是活透视。但在文枢里改了源数据后，要回 Excel 刷新透视缓存，数字才更新。

**同步一直失败，会不会影响我在这台电脑上改文件？**
不会。本地编辑和本地文件永远优先，失败项进队列等重试。设置页能看到失败原因：鉴权失败多半是应用密码过期，重生成再填；一直连不上先查服务地址和网络。

**坚果云还没实测过，我能用吗？**
先说实话：WebDAV 协议本身是通的，开发期在本地测试服务器上全链验过，但坚果云、Nextcloud、群晖三家真实服务还没逐家实测，各家有些小怪癖（比如 ETag 口径）。绑之前先拿几个不重要的文件试一轮同步，确认打开、修改、冲突都正常，再放正式文档。

**我把加密口令忘了怎么办？**
没办法。没有后门，没有找回通道，远端密文解不开。本地明文还在的话，重新绑一个不加密的绑定同步即可。口令请务必记进你自己的密码管理器。

**我加密过的文件，别人没装文枢能打开吗？**
分两种。PDF 工具箱的加密是标准 AES-256 PDF，任何主流阅读器输密码能开。存储同步的客户端加密是文枢自己的 WSE1 格式（格式公开、有规范），日常就靠文枢解，别指望其他软件。

**我的文件在同步里会不会被覆盖丢掉？**
不会，这是设计上写死的：双端同改只生成冲突副本；裁决时落败版先进版本历史；上传新版前旧版先归档。真丢东西的路径我们堵了三层，剩下的风险主要在你手动删文件。

**为什么我开了深色模式，编辑器还是亮的？**
是。深色只作用于应用外壳，文档纸面保持白色，编辑器画布用引擎自带主题。这是为了让你看到的版式接近打印效果。

**最近文档里有一份我没打开过的 sample.pdf？**
那是 PDF 入口的内置示例，它不会被登记进最近文档；你看到的最近文档都是你自己打开或产出的文件。最近文档只存本机浏览器存储里，不联网，记录上限 20 条。

**这软件要收费吗？会不会哪天弹个订阅让我付钱？**
不会。Apache-2.0 开源，没有会员、没有功能锁、没有试用期。也没有账号和默认遥测，崩溃报告要不要发由你手动决定。
